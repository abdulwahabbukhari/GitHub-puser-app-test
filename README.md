## 🚀 Live Kaise Dekhein?

**Option 1: Direct Browser**
```bash
# repo clone karo
git clone https://github.com/YOUR-USERNAME/YOUR-REPO.git

# folder mein jao
cd YOUR-REPO

# kisi bhi .html file ko browser mein open kar do
```

**Option 2: Local Server (recommended)**
```bash
npx serve .
# ya
python -m http.server 8000
```
Phir browser mein kholo: `http://localhost:8000`

**Option 3: GitHub Pages par host karo**
1. Repo ki **Settings** mein jao
2. **Pages** section kholo
3. Branch `main` aur folder `/ (root)` select karo
4. **Save** dabao, 1-2 minute mein link live! 🌐
